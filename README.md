# Regime-Dependent Bitcoin Volatility Forecasting

This repository contains the appendices, data, and replication code accompanying the published paper:

**Regime-dependent Bitcoin volatility forecasting under alternative information sets: evidence from econometric, deep learning, and hybrid models**

Published in *Digital Finance*, Volume 8, Article 63 (2026).

📄 **Read the open access paper:** https://doi.org/10.1007/s42521-026-00229-9

## Repository Contents

- **Appendices and supplementary materials:** Descriptive statistics, full normal-period and crisis-period model rankings, Diebold–Mariano test comparisons, and summaries of models statistically indistinguishable from the relevant benchmark.
- **Data:** Data files used in the empirical analysis.
- **Replication code:** Code and notebooks supporting the estimation, forecasting, and evaluation procedures reported in the paper.
