# Regime-Dependent Bitcoin Volatility Forecasting

This repository contains supplementary materials and replication resources for the paper:

**Regime-Dependent Bitcoin Volatility Forecasting under Alternative Information Sets: Evidence from Econometric, Deep Learning, and Hybrid Models**

At this stage, the repository includes the supplementary material file, which reports descriptive statistics, full normal-period model rankings, full crisis-period model rankings, Diebold–Mariano test comparisons, and summaries of models statistically indistinguishable from the relevant benchmark.

Updated data files, replication codes, further empirical outputs, and extended robustness materials will be added upon publication.
